Additionally, because I desire expertise in web development, I thought I could design a website myself which would serve as proof of my web development skills,. Then the site would become a platform which I can then utilize in the sharing of these thoughts.

Technical Concept:
This Blog aims to integrate a full page Bootstrap template with various other web technologies such as Nodejs, Express, Ejs, etc.

Ejs would provide the templating engine that would be used to render partials in place of page elements that require dynamic contents.

The project will have a landing page which incidentally is the Bootstrap full page template and would be assessible from local NodeJS server on the root route. When the route changes to publish route, the publish page will be displayed, which is where new posts can be made.
